# Rota Monopoly

Crie um jogo de logística estilo Monopoly em português.

O jogador deve comprar armazéns, caminhões, portos e ferrovias.

Adicione sistema de dinheiro, eventos aleatórios, ranking e visual moderno, a movimentação da pessas
